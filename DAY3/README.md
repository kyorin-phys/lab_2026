# 早期体験学習 3日目

ソレノイドバルブとシャッターを組み合わせて、水滴を自動撮影する

## パラメータ

* ソレノイドバルブを開く時間　15～30ms
* シャッターを押すまでの遅延時間 100~300ms
* 水を落とす高さ 30~100cm

定数
* シャッターを開く時間　10ms
* 撮影後、次の撮影までの遅延時間(水面が静かになるまで)　5000ms

### 2分法
* DT=10ms ずつずらして10回連続して撮影する　（どの2点間にあるか）
* 衝突の瞬間がその間にあったら、間隔と時間DTを半分にして、さらに10回撮影
* 繰り返し
* 撮影条件

* どの瞬間を撮るか
* 衝突する瞬間、クラウンができる、水柱ができる　など　いくつかの特徴的な瞬間をできるだけ、クリアに撮影する
