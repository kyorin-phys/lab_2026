# 早期体験学習 1日目

## 撮影の基本

* 絞り、シャッタースピード、ISO感度、ピント合わせ
* 外部ストロボの導入
* カメラのモードの確認（A：絞り優先、S：シャッタースピード優先）
* ISO感度を固定する・自動
* 三脚を使用して、手動で正確にピントを合わせする
* ストロボ光　閃光が光る時間で動きを止める

落下する水滴を繰り返し撮影するのに、必要な要件は何か。
絞り、シャッタースピード、ISO感度、ピント合わせ、ストロボ

### 課題1

* 同一の被写体を絞り値だけ変えて撮影し、被写界深度（ピントが合う範囲）がどう変化するかを確認する

* 水の流れなど動きのある被写体を絞り値固定で、シャッタースピードだけ変えて撮影し、動体ブレを確認する

## マイコンによる自動測定

同じ条件を再現し、統計を取れる程度（N～100）に繰り返し測定を行う

* スイッチボタンを押し、オシロスコープで電圧を測定して、ボタンを何ms押していたか、測定する。
* マイコンで自動測定する
* LEDをランダムに発光させ、光ったらボタンを押し、何ms遅れてボタンを押したか測定する（反応時間）
